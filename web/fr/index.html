Ce qui s'applique depuis le 1er janvier

Le CRS révisé est en vigueur - et le portail change de schéma.

Depuis le 1er janvier 2026, la norme commune de déclaration révisée s'applique en Suisse. L'AFC n'accepte que le schéma 2.0 jusqu'au 14 décembre 2026, et uniquement le schéma 3.0 dès le 16 janvier 2027. Les déclarations pour l'année 2026 - délai 30 juin 2027 - sont les premières à devoir être établies dans le nouveau format : autocertification, procédure de diligence, type de compte et type des personnes détenant le contrôle pour chaque compte.

Source : Directive technique EAR de l'AFC, septembre 2026, chiffre 5.3.1 ; art. 15 al. 1 LEAR.

Fonctions

Tout ce qui sépare votre tableau du portail.

Vérifier comme le portail

Schéma OCDE 2.0 et 3.0, 59 des 65 règles de la Directive technique, jeu de caractères, États partenaires de l'année, IBAN/ISIN - chaque constatation avec code AFC, endroit et remède.

Excel entre, XML sort

Un modèle à quatre feuilles, listes déroulantes et commentaires. Un clic crée le fichier CRS-XML avec tous ses identifiants.

Chiffré pour l'AFC

Le paquet est créé exactement selon le chiffre 3.3.1 de la Directive - AES-256, clé publique de l'AFC, nom de fichier correct pour test et production.

Corrections sans casse-tête

Le registre retient ce qui a été envoyé. L'année suivante, adaptez le même tableau : comptes modifiés en corrections, comptes retirés en annulations, nouveaux comptes en nouvelle déclaration.

Comprendre la réponse du portail

Collez la confirmation de validation - chaque code est expliqué, le registre sait si la déclaration a été acceptée.

Vos données restent chez vous

Pas de serveur, pas d'analytique, pas de cookies. La vérification s'exécute dans votre navigateur ; une politique de sécurité interdit toute autre connexion. Hors ligne après la première visite.

Comment ça marche

Cinq étapes. Aucun manuel nécessaire.

Continuez à faire défiler - les étapes avancent vers la droite.

1

Télécharger le modèle

Le modèle Excel depuis l'app : une feuille pour l'institution, une pour les comptes, une pour les personnes détenant le contrôle, une pour les paiements.

Télécharger le modèle Excel

2

Remplir

Dans votre Excel, comme d'habitude. Les colonnes jaunes sont obligatoires, les listes montrent les codes admis, chaque colonne s'explique par un commentaire.

3

Vérifier

Glissez le fichier dans l'app. Quelques secondes plus tard : vert, ou une liste de constatations - compte, champ, code AFC, quoi faire.

4

Créer et chiffrer

Ouvrez le registre, choisissez une fois la clé de l'AFC, « Créer ». Le paquet est prêt pour le portail EAR.

5

Télécharger et saisir le résultat

Sur le portail, comme avant. Collez la confirmation dans l'app - les corrections de l'année suivante sont préparées.
